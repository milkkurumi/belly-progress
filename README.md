# お腹の経過観察（belly-progress）

妊娠経過の写真を撮りためて、半透明で重ねて大きさの変化を比較する Web アプリ。
写真は端末内の IndexedDB にだけ保存し、外部サーバーへは送信しない。

## 機能（MVP）

- **ゴースト撮影**: ブラウザ内カメラの映像に、前回の写真を半透明で重ねて撮影。撮影時点で構図を揃えられる。ゴーストの濃さ・基準写真は変更可能
- **写真の追加**: カメラが使えない環境では「写真を撮る／選ぶ」ボタンからカメラアプリ・ギャラリー経由で追加
- **比較モード**: 2枚を選んで重ね比べ
  - 透明度スライダー
  - 位置合わせ（ドラッグ移動・大きさ・回転）
  - ワイプ比較（境界ドラッグ）、フリッカー比較（自動で交互表示）
  - 合わせた状態を PNG で書き出し
- **一覧・設定**:
  - 撮影ペース（週1／月1／自由）をユーザーが選択でき、次回目安を表示
  - 出産予定日を入れると写真に妊娠週数ラベルが付く
  - 前回からの経過日数を表示、写真の削除

## 動かし方

```bash
npm install
npm run dev
```

## カメラ利用の注意

ブラウザ内カメラ（getUserMedia）は **localhost（PC）または HTTPS** でしか動きません。

- PC で試す: `npm run dev` → http://localhost:5173 （カメラも動作）
- スマホで試す: HTTPS で公開した URL（例: Vercel へデプロイ）から開く
- どちらでもない環境では、撮影ボタンは使えませんが「写真を撮る／選ぶ」から追加でき、比較・一覧はそのまま使えます

## 技術

Vite + React + TypeScript / 保存は IndexedDB（idb）/ 設定は localStorage
